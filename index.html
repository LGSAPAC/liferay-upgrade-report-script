Liferay Upgrade Program

From the upgrade assessment to go-live. Start with the assessment: identify your version, run the read-only script on your UAT environment and send the report to Liferay.

Why stay up to date with Liferay?

Every release makes your platform safer, faster and easier to build on. Here are the top five reasons to upgrade.

  1. SecurityThe latest security fixes protect your sites, your users and their data.
  2. Supported and compliantStay within Liferay's support lifecycle, with fixes and help when you need them.
  3. New capabilitiesUse what newer releases bring, such as AI features, Objects, client extensions and low-code tools.
  4. Performance and compatibilityRun on current Java versions, databases, application servers and browsers.
  5. Lower cost of ownershipRetire deprecated features and technical debt, and make every future upgrade smaller.

We're here to help. The Liferay upgrade program takes you from assessment to go-live with Liferay Customer Success, the Liferay Upgrade Team and Liferay Support at your side. It starts with a read-only assessment of your installation.

Run the script on UAT

You

Copy the script for your version and run it in the Script console of your UAT / test environment.

Select your version in step 0 first. Each Liferay version needs its own script; a script for another version can report wrong results or fail.
Replaces site names, URLs, instance names, host names, e-mail addresses, the database location and installation paths with placeholders such as site-1. All counts stay the same.
View on GitHub
  1. Sign in to your UAT environment as an administrator.
  2. Open Server Administration (see step 0) and select the Script tab.
  3. Set Language to Groovy, delete the sample code and paste the script.
  4. Click Execute and wait until the page reloads. On large installations this can take a few minutes; don't click again.
  5. The result appears in the Output box. It starts with "Key", "Value", "Description" and ends with lines starting with "uas_.
No Script tab, no Groovy option, or the script is refused?
  • Sign in as an administrator of the default virtual instance (the first instance created). Server Administration is only available to these administrators.
  • The Script Management setting in System Settings (Liferay DXP 2024.Q2 / Portal 7.4 GA120 and later) only controls scripts in Workflow and Objects. You don't need to change it to run this script.
  • Your organization may have switched off scripting for security, for example by disabling the Groovy scripting module. Ask your Liferay administrator to allow it on the UAT environment for the assessment, and to switch it off again afterwards if that is your policy.
  • If you still can't run it, tell Liferay your version and what you see; we'll help.
2

Save the output as a .txt file and send it to Liferay

You

Save the result on your own computer, then send it to Liferay by e-mail or as a support ticket.

Save the output:

  1. Click inside the Output box, select everything (Ctrl+A / Cmd+A) and copy it (Ctrl+C / Cmd+C).
  2. Windows: open Notepad, paste, then File > Save As and choose Text Documents (*.txt).
    Mac: open TextEdit, choose Format > Make Plain Text, paste, then File > Save.
  3. Name the file <company>_<liferay-version>_upgrade-report_<yyyy-mm-dd>.txt, for example acme_dxp-7.3_upgrade-report_2026-11-02.txt.
  4. Check that the last lines start with "uas_ (for example "uas_end_date"). If some lines contain UAS ERROR, send the file anyway: it tells Liferay what could not be read.

Send it, by e-mail or as a support ticket. Send the report only as an attachment; don't paste it into a website or chat.

Option A: e-mail

  1. E-mail the .txt file as an attachment to support@liferay.com.
  2. Put your Liferay customer success contact in CC, if you know who it is.
  3. Use a subject such as Upgrade assessment report – <company>.
Start the e-mail Opens your e-mail program with the address and subject filled in. Attach the saved file yourself.
Add your company and customer success contact to the e-mail

Option B: support ticket (Liferay subscribers with a Help Center account)

  1. Go to the Liferay Help Center and sign in with your liferay.com account.
  2. Choose Contact Support (or Submit a request) to open a new ticket, and select your project.
  3. Use the subject Upgrade assessment report – <company>, and in the description say that this is the report for the Liferay upgrade program.
  4. Attach the saved .txt file and submit the ticket.
  5. If you know your Liferay customer success contact, let them know the ticket number.

Liferay replies on the ticket and notifies you by e-mail.

The report contains technical details (versions, counts, plugin and site names) but no content from your sites, and the scripts do not read passwords. To hide names and addresses, use the privacy option in step 1.
